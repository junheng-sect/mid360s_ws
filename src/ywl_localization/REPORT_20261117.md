# YWL 固定先验地图定位 · 室内单包对照

2026-11-17，在 Orange Pi 5 Max 上完成 ROS Noetic 独立构建和 1× 隔离回放。
YWL 在包开始约 5.80 秒切入固定地图并持续定位到包尾，收到并处理 1,520 帧雷达，
其中 1,463 帧发布地图系位姿与同刻速度。单包 P99 实时性目标通过。

## 数据和版本

- 原始数据为 2026-11-14 的 `indoor_fly_raw_000001.bag`，时长约 152 秒，含 1,520 帧
  `/livox/lidar` 和 30,400 条 `/livox/imu`。板端与 KIOXIA 副本的 SHA-256 一致。
- 先验来自独立采集的 2026-10-21 室内地图 `20261021_110311_indoor`，PCD 为 91,910 点。
- YWL 运行时代码为 `642e757`，上游为 `93da4f462b8da16679c18a8aea9545ed4cb3c71b`。
  FAST-LIO2 基线从 `52c8665b76a3580fcb2f8aea7ea7c385dc7b55c8` 干净构建。
  两套算法逐次运行，ROS master 各自隔离。生产桥接与 DLL 工作树没有参与对照。
- 双窗口初值由本次重新播放原始数据后得到的基线里程计和静态 TF 产生。首次在线
  初始化在静止段结束前未完成双确认。最终使用已有离线启动模拟器，将两次求解期间的
  数据时钟暂停，保留现有几何、静止与确认门限。数据时间的两个窗口约为 1.3–3.3 s
  和 3.3–5.3 s，求解实际耗时约 8.1 s 和 2.8 s。该初值可用于复现同包对照，
  在线初始化成功率及耗时仍待验证。
- 原始 bag 与地图 SHA-256、参数、初始化原始输出和逐帧记录保存在 KIOXIA
  的 `Log analysis/outputs/20261117_ywl_indoor_fly/`。该包为算法输入，实验未使用 ULog。

## 1× 对照结果

| 指标 | FAST-LIO2 | YWL |
|---|---:|---:|
| 发布里程计帧数 | 1,517 | 1,463 |
| 初值之后到包尾的原始扫描覆盖 | 1,462 / 1,462 | 1,462 / 1,462 |
| 旁路接收雷达到接收里程计 P95 / P99 | 36.8 / 44.0 ms | 78.7 / 84.2 ms |
| 估计器平均 CPU（单核心为 100%） | 43.9% | 56.3% |
| 估计器进程 RSS 峰值 | 172.2 MiB | 155.5 MiB |
| 首末静止段的均值位置差 | 7.8 cm | 2.1 cm |

YWL 扫描处理 P50/P95/P99 为 30.7/68.5/74.6 ms，收到输入至发布的节点内 P99 为
79.1 ms。处理队列峰值为 1 帧。唯一超过 100 ms 的是切图帧，处理 214.8 ms，
包含先验点变换与索引重建。其余扫描处理最大 79.5 ms。输入停止约 0.55 s 后进入
`STALE`，此后无新的有效位姿。

1,463 对发布帧的三维位置差 P50/P95 为 9.2/11.8 cm，姿态差 P95 为 1.76°。
首末位移只描述两套估计在这份包上的回访一致性。缺少独立检查点真值，无法判断
哪条轨迹更接近真实位置。端点窗口取首个配对帧之后 0.6 s 和最后 3 s。

## 验证与后续

- 四项初值单测通过，覆盖刚体变换、同刻插值及缺失配对、静止与新鲜度、双窗口确认。
- 降速测试和 1× 全量回放均完成固定地图交接。索引点数持续为 91,910，1,463 帧位姿
  协方差均通过有限值、对称和对角线检查，速度与位姿时间戳逐帧对应。
- 隔离故障测试通过，包括错图初值、非法地图、运行中地图或外参变更、LiDAR 时间
  回退、冲突的重复初值、无有效点面匹配以及断流。
- 回放 ROS 发布者为 `/ywl/*` 加 ROS 日志话题。下一阶段应补在线初始化、长时资源
  观察和板端实机旁路验证。导航接入和飞行验收仍待独立验证。

复现请使用本包 README 中的构建、种子生成、对照回放与故障测试命令。
